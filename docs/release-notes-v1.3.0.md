# v1.3.0 — DSH 0.2.2 兼容与协作版同步

修复新版 DSH Desktop 中工作助手显示“加载失败”、新建会话报 `tool-subagent-list-agents ... never started`：0.2.2 已把 `list_agents` 合并到主控制模块。本版只在运行时仍提供旧入口时才加载它，避免引用已移除的导出，也避免重复注册。

Windows 安装包包含当前 .coop.7 协作功能：漏回应时由同款模型补出正文后继续原调用，任务不因沟通检查暂停；过程清单在工具结果返回后按实际证据及时更新，收尾核对作兜底，不自动勾满。

修复安装器把本地维护版链接切回另一份旧包的问题：保留 DSH_HOME 内已有的工作助手 link 目录，拒绝较旧预设覆盖更新版本，安装后核对实际链接文件、版本与运行时模块。已下载的 v1.2.x 旧 EXE 不会自动获得这些保护，请换用本版。

安装：完全退出 DSH，包括托盘；运行本 Release 的独立 EXE 或桌面 ZIP 内的 EXE，选择原 DSH 程序和 DSH_HOME。启动后选择“工作助手”。已有文件和技能会先备份，用户添加的技能保留。

同一 Release 提供 DSHA v1.3.0 ZIP，包含共享提示词、240+3 技能和列表入口兼容模块。桌面专用 host 插件不加载到手机运行时，安卓真机未验证；请按手机说明安装。

验证包括：40项隔离安装检查（独立EXE、特殊路径、旧配置修复、本地链接保留和拒绝降级）、DSH 0.2.2-rc.1 上8项会话/清单检查和13项回应回归、真实随包CLI、移动包结构和入口兼容分支测试。测试不等于所有电脑或安卓设备均已实测。

不包含本机个人会话诊断器，也不声称已解决远端模型重复生成的问题。
