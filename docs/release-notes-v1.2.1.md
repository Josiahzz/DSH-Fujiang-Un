# v1.2.1 — Desktop 新装配置修复

新装 DSH 的 `cordis.patch.yml` 默认带有注释和空列表 `[]`。旧安装器只处理整个文件等于 `[]` 的情况，追加 `- id: fujiang` 后造成无效 YAML；依赖同步仍然成功，因此安装器可能提示完成，但 Desktop 启动时报配置解析错误。

本版在追加配置前移除空的根列表，同时保留注释、已有配置和嵌套空列表。对于已经被旧版本写坏的同类文件，即使 `fujiang` 项已经存在，重跑本版也会修复。修改前仍会备份原配置。

恢复：完全退出 DSH，包括启动错误窗口和托盘；运行本 Release 的 `DSH-Fujiang-Installer.exe`，选择原来的 DSH 程序和 DSH_HOME，安装完成后启动。无需删除会话、账号配置或重新安装 DSH。

验证：35 项隔离安装检查通过；复现旧版“提示安装成功但配置无法解析”，修复后用 DSH 0.2.1-rc.5 自身的解析器通过；真实随包 CLI 链接检查通过。独立 EXE 已包含完整 payload。尚未在报告问题的朋友电脑上运行，仍需对方重跑确认。

本次只修改 Windows 安装器及说明和回归测试，预设和技能字节保持 v1.2.0。DSHA 手机包继续附带原 `DSH-Fujiang-DSHA-v1.2.0.zip`，不需要更新。
